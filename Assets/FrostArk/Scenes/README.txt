FrostArk Session Bootstrap fixture

This folder is intentionally tracked. The actual SessionBootstrap.unity scene is
generated by Unity Editor (not by an unverified YAML approximation).

Explicit Editor command:
FrostArk.Unity.Editor.FrostArkSessionFixture.CreateScene

It creates/updates only Assets/FrostArk/Scenes/SessionBootstrap.unity using a
VContainer WorldSessionScope and WorldSessionPresenter. It does not run on
Editor startup and does not modify the starter SampleScene.

Generate and import only in a real authorized Unity 6000.6.0f1 session,
inspect the generated YAML/meta diff and run EditMode tests before G2 PASS.
